# CYSE635-MNIST-CNN
CNN implementation and analysis for MNIST handwritten digit classification using PyTorch.
This project implements a LeNet-style convolutional neural network with two convolutional layers and three fully connected layers. The model was trained on the MNIST dataset using Adam optimization, weight decay, validation monitoring, early stopping logic, and a ReduceLROnPlateau learning-rate scheduler.
The final model achieved a test accuracy of 95.94%.
The notebook includes:
- model implementation
- training and validation
- test evaluation
- classification report
- confusion matrix
- training and validation curves
- convolutional filter visualizations
- first- and second-layer feature maps
